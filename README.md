# UiFeedback（UI指摘ボード）

スクリーンショットに番号付きの指摘（ピン・矢印・囲み）を置いて、AIに修正を頼むための「注釈入り画像」と「プロンプト」を作るWebツールです。

公開ページ: https://rinsan1120.github.io/UiFeedback/

## 使い方

1. 画像を読み込む（ページで Ctrl+V 貼り付け／ドラッグ＆ドロップ／「画像を開く」）
2. ツール（ピン・矢印・囲み）で画像の上に注釈を置く。置くたびに番号が連番で付く
3. 右側のリストに、番号ごとの指摘文を書く
4. 「画像をコピー」（または PNG保存）と「プロンプトをコピー」を押して、AI（Claude / ChatGPT / Codex など）のチャットに貼る

- 注釈は選択してドラッグで移動、Deleteキーまたはリストの「削除」で消せる。消すと番号は詰め直される
- プロンプトの雛形は編集でき、`{list}` の位置に番号リストが差し込まれる
- 作業内容（画像・注釈・指摘文・雛形）はブラウザ内（IndexedDB）に自動保存され、開き直すと続きから再開できる。画像が外部に送信されることはない

## 実装

`index.html` 1ファイルのみ（HTML/CSS/JS、ビルド不要）。GitHub Pagesで配信。
